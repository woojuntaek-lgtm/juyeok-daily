# 오늘의 주역 한 괘

주역 64괘로 하루 한 괘를 뽑아 보는 **성찰용 웹 앱**입니다. 파일 하나(`index.html`)로 동작하며 서버·로그인·광고가 없습니다. 휴대폰 화면에 맞춰 만들었습니다.

> 실행: `index.html`을 브라우저로 열기 / GitHub Pages 주소: _(여기에 링크를 적어 주세요)_

## 뽑는 방식 (5가지)

| 방식 | 설명 |
|---|---|
| 기본 | 날짜만으로 정해지는 괘. 누구에게나 같은 날 같은 괘 |
| 날짜 연결 | 매화역수 방식. 음력 연·월·일과 일진으로 상괘·하괘 계산 |
| 지금 이 순간 | 매화역수 시각법. 뽑는 순간의 음력 날짜와 시(時)로 괘·동효·변괘 계산 |
| 동전 던지기 | 동전 세 닢을 여섯 번 던져 효를 쌓음. 노음·노양은 변효가 되어 변괘와 효사를 봄 |
| 나만의 괘 | 이름과 생년월일을 섞어 사람마다 다른 괘 |

모든 괘에 핵심 뜻, 스스로에게 묻기, 오늘의 한 걸음, 여섯 효의 효사(원문+풀이)가 들어 있습니다.

## 파일 구성

```
index.html                앱 전체(데이터 내장)
data/hexagrams_64.json    64괘 기본 정보와 설명 문구
data/yaosa_384.json       효사 원문과 풀이 (괘 번호 → [원문, 풀이] × 6, 건·곤은 용구·용육 포함)
LICENSE                   코드: MIT
LICENSE-CONTENT.md        풀이 문구·데이터: CC BY-NC 4.0
```

## 개인정보

입력한 이름·생년월일과 뽑은 기록은 **사용자 기기의 브라우저(localStorage)에만** 저장되며 외부로 전송되지 않습니다.

## 면책

성찰·오락 목적의 참고 도구입니다. 미래를 예언하거나 결과를 보장하지 않으며 의료·법률·투자·심리 진단이나 전문 상담을 대신하지 않습니다. 이용으로 인한 결과에 대해 보증하지 않습니다.
